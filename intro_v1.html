video-auto-cut（AI 剪辑对接）

让 AI agent 通过 MCP 直连你电脑上的本地视频编辑器 OpenChatCut，用对话指挥剪辑——读时间线、摆 B-roll、加字幕、放动效、导出成片，全程本地、先审后改。

100%素材本地处理
manual默认确认模式
秒级制作分镜
6 类故障恢复场景

能做什么

  • 对话式剪辑：读取项目时间线，给出剪辑方案，编辑器内确认后一键生效
  • 秒级制作分镜：起止秒 / A-roll / B-roll / 镜头内容 / 对应文案，确认后才动手
  • A-roll 定稿 → B-roll 后补：以真实口播时间轴为基准，在指定窗口叠 B-roll
  • 素材智能选段：长素材多窗口复用取有效区间，短素材用慢放/循环/定格补足
  • 按需加载专项指南：字幕 / 转写 / MG 动效 / 生图生视频 / 音色 / 导出
  • 故障恢复：连接拒绝、会话卡死、提案待审等 6 类场景逐条处置

适合谁 · 解决什么问题

目标用户痛点 → 解决
用 AI agent 剪视频的内容创作者口播反复手工拖时间线 → agent 直读项目状态按分镜批量操作

连不上编辑器就卡死的场景agent 空转 → getting-started / known-errors 双文档端到端恢复

能带来哪些好处

  • 省时间：一句话给出可审阅的剪辑提案，不用自己拖时间线
  • 少返工：秒级分镜先确认，避免 B-roll / 动效 / 字幕全做完才发现错位
  • 自动闭环：A-roll 定稿后 B-roll 自动按窗口补位，素材复用不浪费
  • 数据可见：编辑提案、确认、应用都在编辑器内可视化完成
  • 出错可控：手动模式 + 原子撤销 + 六类故障手册，不怕 agent 乱动

功能核心点

核心机制设计要点
MCP 直连本地编辑器默认端点 localhost:5199/api/external-mcp/mcp；bearer token 从编辑器 Settings → MCP 复制，凭据不进仓库
会话级草稿begin_edit_session 开草稿 → review_edit_session 统一应用；reuseExisting 续用未完成草稿
秒级分镜确认未确认不开始 B-roll / 动效 / 字幕 / 音乐；动效贴片须写明内容、位置、起止秒并避开人脸字幕区
A-roll → B-roll 工作流口播时间线是唯一时间基准；B-roll 时长由目标窗口决定，支持源区间选取、慢放、循环、定格
按需加载专项指南load_skill 只读、无需编辑会话；progressive exposure 减少首轮工具清单
