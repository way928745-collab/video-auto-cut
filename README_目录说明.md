# 目录结构说明（本版本包）

  版本目录/
  ├─ 使用方法.text        ← 先读这个：装进哪个文件夹、怎么触发（面向小白，不依赖 agent 能力）
  └─ video-auto-cut/   ← 技能文件夹：整体复制到你 agent 的技能目录里
     ├─ SKILL.md           ← 技能主文件（agent 读取的执行规范，含 DIKO 授权条款）
     ├─ scripts/ + diko_kit/  ← 使用授权模块（凭据仅存你本机；无完整性锁，整体删除即完全卸载）
     ├─ agents/ + assets/ + references/  ← agent 对接配置、图标与工作流/排错文档
     ├─ README.md          ← 功能总览（带知识星球推广与二维码）
     ├─ intro_v1.html …    ← 介绍页（浏览器打开：是什么/能做什么/好处/优势/证据/核心点；复杂信息用表格、有数据用折线/柱状/饼图，图表数据来自真实台账；历史版本页累积保留）
     ├─ images/            ← 二维码等图片（README 以相对路径 ./images/xxx 正确引用，路径全小写）
     └─ readmev1/          ← 基础版 README 原样快照（无升级标注、无推广信息）

层级硬约定：技能文件夹内只放 agent 加载的内容（SKILL.md、模板、脚本）；「使用方法.text」放在上一层（版本目录），避免被一起装进技能目录。
